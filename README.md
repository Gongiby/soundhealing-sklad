# 🕯 SoundHealing.by

**Система управления магазином терапевтических звуковых инструментов**

Версия 1.0 · PWA · React 19 · TypeScript · Vite

---

## 🎯 Что это такое

Полноценная система для управления розничным магазином звуковых инструментов:
- Глюкофоны, чакрофоны, поющие чаши, гонги, космограммы, шейкеры, rainstick-и, камертоны
- Учёт поставок с **мультивалютным** расчётом себестоимости (BYN, RUB, USD, EUR, CNY)
- Автоматическая генерация **QR-кодов 45мм** для каждого инструмента
- Печать **PDF 45мм** этикеток для Bluetooth-термопринтера
- Скачивание **JPG 45мм** для отправки в мессенджеры
- Сканер QR через камеру телефона
- Корзина со скидками и количеством
- Продажи с Telegram-уведомлениями и чеками
- Возвраты, резервирования, повтор чеков
- Касса: **X-отчёт** за день с разбивкой по менеджерам
- Бэкапы (JSON + отправка через Telegram)
- Облачная синхронизация между устройствами (Supabase)
- Аудит-лог всех действий
- Глобальный поиск (Ctrl+K)
- Авторизация с ролями (директор / менеджер)

**Стоимость:** 0 BYN/месяц (всё работает на бесплатном стеке)

## 🚀 Настройка с нуля (production)

### 1. Supabase (облачная база — опционально)

1. Зарегистрироваться на [supabase.com](https://supabase.com) (бесплатно)
2. Создать новый проект
3. SQL Editor → New Query → вставить содержимое `supabase/init.sql` → Run
4. Settings → API → скопировать **Project URL** и **anon public key**
5. В приложении: **Настройки → Облачная синхронизация** → вставить URL и ключ → **Тест** → **Сохранить**
6. Если есть данные в localStorage: нажать **"📦 Перенести данные в облако"**

### 2. Telegram-бот (уведомления и чеки — опционально)

1. Открыть [@BotFather](https://t.me/BotFather) в Telegram
2. Команда `/newbot` → следовать инструкциям → получить токен
3. Узнать свой Chat ID через [@userinfobot](https://t.me/userinfobot)
4. В приложении: **Настройки → Telegram-бот** → вставить токен и Chat ID → **Тест**
5. Включить галочки "Уведомления директору" и "Отправлять чеки клиентам"

### 3. Развёртывание

**Самый простой способ (Netlify):**
1. Открыть https://app.netlify.com/drop
2. Перетащить папку `dist/` (после `npm run build`)
3. Получить URL вида `random-name.netlify.app`

**На своём домене:**
1. В настройках Netlify → Domain settings → Add custom domain
2. В DNS регистратора: CNAME `app.soundhealing.by → random-name.netlify.app`
3. SSL выпустится автоматически

## 🎯 Основной workflow

### Для менеджера:

1. **Открыть сканер** (кнопка "Сканер" в меню)
2. **Включить камеру** (кнопка "Включить камеру")
3. **Сканировать QR** инструмента — он попадёт в корзину
4. Сканировать следующие инструменты...
5. **Настроить скидки/количество** в корзине (если нужно)
6. **Оформить продажу** → выбрать клиента → подтвердить
7. Готово! Чек отправляется клиенту в Telegram

### Для директора:

1. **Принять поставку** (Поставки → + Новая поставка):
   - Указать дату, поставщика (или создать нового)
   - Добавить позиции (название, категория, кол-во, цена закупки, цена продажи)
   - Курсы валют зафиксируются автоматически
2. **Напечатать этикетки** (раскрыть поставку → кнопка "Этикетки")
3. **Смотреть отчёты** (Отчёты → 5 типов)
4. **Закрывать смену** (Касса → выбрать день → скачать X-отчёт)

## 🔒 Безопасность

- ✅ Пароли хэшируются через SHA-256 (Web Crypto API)
- ✅ Сеансы 7 дней с уникальным токеном
- ✅ Маржа и себестоимость НЕ доступны менеджерам (на уровне сервера)
- ✅ RLS в Supabase (Row Level Security)
- ✅ Опасные действия требуют удержания кнопки 2 сек
- ✅ Защита от случайного сканирования (debounce 1.5 сек)
