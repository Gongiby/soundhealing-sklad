# 🚀 SoundHealing.by — Инструкция по обновлению

## Стандартный процесс обновления (для пользователя)

1. Получите ZIP-архив вида `SoundHealing-UPDATE-R26.zip`
2. Распакуйте его **в ту же папку**, где находится текущая версия (рядом с `START_UPDATE.cmd`)
3. Запустите `START_UPDATE.cmd` **двойным кликом**
4. Дождитесь завершения (обычно 1-2 минуты)
5. Готово! Откройте приложение

Скрипт `update.cjs` автоматически:
- ✅ Найдёт папку приложения
- ✅ Создаст резервную копию в `.backup-<timestamp>/`
- ✅ Проверит наличие всех ключевых файлов
- ✅ Установит новые зависимости (`npm install`)
- ✅ Запустит проверку проекта (`npm run check`)
- ✅ Соберёт production-версию (`npm run build`)
- ✅ Сохранит подробный лог в `UPDATE_LOG_<date>.txt`

## Если что-то пошло не так

1. Откройте `UPDATE_LOG_<дата>.txt` — там подробная история
2. Если приложение сломалось — найдите папку `.backup-<timestamp>` (создаётся автоматически перед каждым обновлением)
3. Скопируйте из неё файлы обратно в корень

## Развёртывание на хостинг

После успешного обновления запустите `START_DEPLOY.cmd` — он соберёт проект и покажет инструкции для каждого хостинга.

## Что НЕ делает скрипт обновления

- ❌ НЕ трогает базу данных (товары, продажи остаются на месте)
- ❌ НЕ публикует на хостинг автоматически (для этого — START_DEPLOY.cmd)
- ❌ НЕ меняет пароли пользователей
- ❌ НЕ удаляет старые данные
